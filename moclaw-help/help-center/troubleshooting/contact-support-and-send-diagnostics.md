# Contact Support And Send Diagnostics

If you need to report a bug, use **Bug Report** / **Report a Bug** in the top
right controls when it is visible. Describe what happened, what you expected,
and attach a screenshot if it helps.

## If Bug Report Is Missing

The Bug Report entry only appears when MoClaw's feedback path is available in
the current environment. If you do not see it, collect the same details below
and use the support path you normally use for your account or workspace.

## What To Include

Send only the details needed to locate the issue:

- Your account email.
- Approximate time and timezone.
- What you were trying to do.
- What happened and what you expected.
- The exact visible error text.
- A screenshot of the visible MoClaw UI state, if useful.
- Any **Reference ID** or **Copy reference** diagnostic text shown in the UI.
- Relevant file name, connector name, schedule/task name, invoice/checkout
  reference, or model tier if the issue is about one of those areas.

## Screenshots

The in-app Bug Report form supports an optional image screenshot. You can attach
or paste a screenshot. Images must be 5 MB or smaller.

Only one screenshot can be staged at a time. If you choose or paste another
screenshot, it replaces the previous one. The file picker is for screenshots,
not logs, PDFs, archives, or other non-image files.

The submit button stays unavailable when the description is empty, while the
screenshot is still loading, or while a report is already being sent. If submit
fails, MoClaw keeps your description and screenshot so you can retry.

## Reference ID

If a failed message or terminal notice shows **Reference ID**, include it in the
report. If the row has **Copy reference**, use that copied text instead of
pasting a full terminal log. The copied reference is compact diagnostic text,
not the full raw terminal output.

## Community Help

You can also ask questions, share feedback, and follow updates in the official
MoClaw community channels:

- Discord: <https://discord.gg/QXFkEbrFn9>
- Telegram: <https://t.me/MoClaw_AI>
- X (Twitter): <https://x.com/MoClaw_AI>

Joining the community Telegram or Discord group is not the same as connecting
a Telegram or Discord chat channel in **Workspace > Channels**; community
groups are for discussion and announcements, not a chat entry point to your
MoClaw agent. For account-specific or billing issues, use the support path
above instead of posting private details in public groups.

## What Not To Send

Do not send:

- passwords;
- verification codes;
- full card numbers or CVV;
- API keys;
- OAuth tokens or authorization codes;
- cookies;
- signed URLs;
- private repository tokens;
- unrelated personal data;
- full raw logs unless support specifically asks for a scoped, redacted
  snippet.

Redact secrets from screenshots before sending them.
