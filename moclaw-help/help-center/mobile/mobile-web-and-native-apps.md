# Mobile Web And Native Apps

There are two separate mobile topics:

- Using MoClaw from a mobile browser.
- Using a native iOS or Android app.

Do not treat these as the same thing.

## Mobile Web

MoClaw's web app adapts to narrow and mobile screens. On mobile, the current
Session Dock becomes a full-screen overlay and keeps the same open file tabs.
Other surfaces may appear as sheets, overlays, or collapsed sections.

If a panel or button looks missing, check whether you are on a phone, tablet, or
narrow browser window.

## Native iOS And Android Apps

Native iOS and Android clients are documented in product work, but public App
Store or Google Play availability is not confirmed by the current help
knowledge base.

If you are asking whether a native app is available for your account, check the
current product UI or ask support. Do not assume beta, TestFlight, Google Play
closed testing, or production access unless support confirms it.

## What To Send Support

- Account email.
- Whether you mean mobile browser or native app.
- Device and operating system.
- Screenshot of the current MoClaw UI if a layout element is missing.
- The task you are trying to complete.
