# Skills And Commands

MoClaw has two related but separate surfaces:

- **Skills** in the left sidebar open loaded capability instructions.
- **Commands** in the chat composer are shortcuts opened with `/`.

## View Skills

Open **left sidebar > Skills**. Each skill card shows a name and whether it is a
**System** or **User** skill. Hover the description when it is truncated.

If the section says **No skills**, the current workspace does not have skills to
show, or the workspace is not ready yet.

## Use Commands

Click the `/` button in the chat composer, or type `/` at the start of a
message. MoClaw shows available commands. Type to filter, then select a command
with Enter or by clicking it.

Current commands include:

- `/new` starts a new conversation in the current session. It does not delete
  earlier messages.
- `/stop` stops the current execution.

Commands are not the same as skills. Typing `/<skill-name>` does not necessarily
run a skill.
