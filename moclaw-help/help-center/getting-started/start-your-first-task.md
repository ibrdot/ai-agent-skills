# Start Your First Task

Open `/chat` and tell MoClaw what you want done. If **Start here** examples are
visible, click one to fill the composer, edit it, then send.

## Write A Good First Prompt

Useful prompts include:

- The outcome you want.
- Any background context.
- Files, links, or services MoClaw should use.
- Constraints such as audience, format, deadline, or style.
- Where the result should go, such as an artifact, document, email draft, or
  scheduled task.

Example:

> Research these three competitors, compare pricing and positioning, then make
> a concise report with sources and recommendations.

## If Start Here Is Not Visible

That is okay. The **Start here** quick-start surface appears only in some empty
first-run chat states. You can always type directly in the chat composer.

If you want a fresh conversation, use `/new`. That starts a new conversation in
the current session; it does not delete previous chats or clear workspace files.

## Using A Starter Link

Some links open a starter preview at `/start/...`. A starter preview shows an
example task flow before you run it yourself.

Use **Try yourself** to bring the starter into your own `/chat` workspace. You
may need to sign in first. If you type in the starter composer before trying it,
that text can become your first message in the live chat.

If you use **Try yourself** with an empty composer, MoClaw can bring the starter
workspace into `/chat` without sending a first message automatically.

If the page says it could not load the onboarding, the link may be unavailable
or expired. If the page says it could not save the starter handoff, your browser
may be blocking storage; try again in a normal, non-private window.

## Before Sending

- Attach local files if MoClaw needs them.
- Reference existing workspace files with `@` when available.
- Connect GitHub, Google Workspace, Linear, or another service before asking
  MoClaw to act there.
- For local browser state or local files, open the task in MoClaw Desktop; the
  browser Web App does not provide local capabilities.
