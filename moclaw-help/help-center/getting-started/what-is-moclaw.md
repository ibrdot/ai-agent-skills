# What Is MoClaw?

MoClaw is a personal AI agent that works inside your own **AI Cloud Computer**.
You give it tasks in chat, and it can use a browser, files, commands,
connectors, skills, and schedules to get work done.

MoClaw is not just a chatbot. It can take action in a workspace, produce files,
and show you what it is doing.

## What MoClaw Can Help With

- Researching web pages and collecting information.
- Working with files, documents, spreadsheets, images, and generated outputs.
- Using connected services such as GitHub, Linear, or Google Workspace when
  available for your account.
- Running longer tasks in its cloud workspace.
- Keeping useful outputs as artifacts you can open, reference, or download.
- Running scheduled tasks when schedules are available.

## What MoClaw Is Not

- It is not only a chat wrapper around a model.
- It does not use your local computer by default.
- It does not automatically get access to every third-party account or file you
  own.
- It should not be treated as a confirmed roadmap promise for every feature that
  appears in docs or code.

## Where To Start

Open `/chat`, describe the task you want done, and attach or reference any files
MoClaw should use. If **Start here** examples are visible, click one to fill the
composer, edit it, then send. If the task needs a connected service, open
the left sidebar and check **Connectors**.
