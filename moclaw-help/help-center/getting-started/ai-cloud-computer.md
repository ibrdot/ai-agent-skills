# What Is The AI Cloud Computer?

The AI Cloud Computer is MoClaw's cloud workspace for your tasks. It is where
MoClaw opens pages, reads and writes files, runs commands, uses tools, and saves
outputs.

Think of it as the computer MoClaw uses to work for you.

## What Happens There

- Browser work, such as opening pages, reading content, clicking, and taking
  screenshots.
- File work, such as reading, editing, generating, and previewing workspace
  files.
- Command or script work when a task needs it.
- Artifact creation, such as reports, documents, images, spreadsheets, and other
  files that MoClaw surfaces for you.

## Cloud Workspace vs Local Computer

The AI Cloud Computer is not your personal laptop or desktop. By default,
MoClaw works in the cloud workspace and does not access local files or local
browser sessions.

If you need MoClaw to use local browser state or local files, connect MoClaw
Desktop. Local file tools are currently fixed to the desktop user's Home
directory, and the operating system's own permissions still apply.

## If The Workspace Has Trouble

If the workspace is unavailable, wait for recovery, retry the message, or use a
restart action if the UI offers one. If the problem repeats, collect the visible
error copy, account email, approximate time, and any reference id shown in the
UI.
