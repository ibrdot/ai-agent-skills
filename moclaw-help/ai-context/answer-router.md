## Status Handling

| Card Status | How To Answer |
|---|---|
| `verified` | Answer directly and give the UI path. |
| `needs_verification` | Answer conditionally and tell the user how to check current availability. |
| `conflicted` | Explain the safe distinction and avoid one-rule summaries. |
| `draft` | Use only as support guidance, not as a final product promise. |
